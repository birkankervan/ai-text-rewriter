Setup guide

Translation works right after install, for free. Rewriting needs your own API key, which takes about two minutes to connect.

1. Install

  1. Download chrome-mv3-prod.zip from the latest release and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin the extension from the puzzle-piece menu so the popup is one click away.

Tabs that were already open need a reload before the Rewrite and Translate buttons appear on them.

2. Connect an AI provider

Rewriting and AI translation use your own key. The extension talks to the provider directly; nothing goes through a server of ours.

  1. Open Settings: click the extension icon, then the settings button in the popup.
  2. Under AI provider, pick a card: OpenRouter, OpenAI, Google Gemini or Groq.
  3. Paste your API key and click Connect.
  4. Choose a Model. The list loads from your provider.

Once connected, the card shows In use. Your key is stored on this device only and is never synced to your Google account. You can replace or remove it at any time.

3. Get an API key

Create a key with the provider you picked. Usage is billed by the provider, not by this extension.

4. Translation

Translation is free and needs no key. By default it uses Google Translate and sends the selected text there when you click Translate.

To translate with your AI provider instead, open Settings and go to Languages → Translation engine, then choose AI provider. The option is available after you connect a provider. The same section sets your default languages.

5. Use it on a page

  1. Select text. A small button appears next to the selection.
  2. In a text box or editor the button is Rewrite. Pick a tone, optionally tick Fix Grammar, choose to keep the original language or rewrite into another, and click Generate.
  3. On regular page text the button is Translate. Click it and the translation streams in, in your default language; pick another language in the panel if you need one.
  4. Click Replace Text to put a rewrite back into the field, or copy the result.

Nothing is sent when you only select text. A request starts after you click.

6. Use the popup

For text that isn't on a page, click the extension icon. The popup has separate Rewrite and Translate tabs: paste your text, choose a tone or language, and click Generate or Translate.

7. History

Rewrites and translations are saved in your browser. Open History from the top of the Settings page to search, filter, copy or delete entries, or clear it all. Entries are deleted automatically after 15 days.

Troubleshooting

The model list doesn't load

Check the API key. Make sure it was copied completely, belongs to the provider card you selected, and is still active in the provider's dashboard. Replace it in Settings and try again.

OpenRouter free models fail or slow down

Free models on OpenRouter have rate limits, and some require data collection to be allowed in your OpenRouter privacy settings. Wait a moment, try another model, or use a paid one.

Nothing happens when I select text

Reload the tab. Pages that were open before you installed the extension don't have it loaded yet.

Still stuck? Open an issue on GitHub or email support.
