### Category

Primary suggestion: **Productivity → Tools**. Alternative: **Productivity → Communication**.

### Description (plain text, ~2,480 chars)

```
Select text on any page and rewrite or translate it in place. No copy-paste into another tab, no account, and nothing is sent until you click.

HOW IT WORKS
1. Select text. In a text box or editor you get a Rewrite button; on regular page text you get a Translate button.
2. Click the button. A small panel opens next to your selection.
3. Pick a tone or language, then copy the result or replace the selected text in the field with one click.

FEATURES
• Rewrite in 6 tones: Professional, Friendly, Formal, Casual, Concise, Expanded
• Optional "Fix Grammar" pass for spelling, punctuation and grammar
• Rewrite and translate in one step: keep the original language or rewrite into another
• Replace Text puts the result back into inputs, text areas and rich-text editors
• Translate selected page text into 21 languages with automatic source-language detection
• Results stream in as they are written; stop a request at any time
• Toolbar popup for text that isn't on a page: separate Rewrite and Translate tabs
• History of your rewrites and translations with search, filters, copy and delete
• Light, dark or system appearance, plus an optional pure-black mode
• Keyboard friendly: Escape closes the panel, results can be copied with Enter

PRIVACY
• Nothing is sent when you select text. A request starts only after you click the Translate button, Generate, or Translate in the popup.
• No backend, no account, no analytics. The extension talks directly to the service you chose.
• Rewrites and AI translations go to your chosen AI provider using your own API key.
• Free translation sends the selected text to Google Translate.
• API keys and settings stay on this device and are never synced to your Google account. History stays in your browser and is deleted automatically after 15 days, or whenever you clear it.

SUPPORTED PROVIDERS & LANGUAGES
AI providers (bring your own key): OpenRouter, OpenAI, Google Gemini, Groq. Choose any model your provider lists; the model list loads from the provider.
Free translation: Google Translate, no key needed.
Languages: English, Spanish, French, German, Italian, Portuguese, Dutch, Russian, Chinese (Simplified), Japanese, Korean, Arabic, Hindi, Turkish, Greek, Hebrew, Swedish, Polish, Vietnamese, Thai, Georgian.

SETUP
Translation works right after install, for free.
Rewriting needs your own API key: open Settings, pick a provider, paste your key and choose a model. OpenRouter offers some free models. Provider usage is billed by the provider, not by this extension.
```

## 3. Chrome Web Store privacy tab

### Single purpose

```
Rewrite or translate text the user selects on a web page. The user selects text, clicks the extension's button, and gets a rewritten version (via the user's own AI provider API key) or a translation (via Google Translate or the user's AI provider), which they can copy or insert back into the field.
```

### Permission justifications

Built manifest permissions: `storage`, `alarms`. Host permissions: the 5 API origins below. Content script: `<all_urls>`, `all_frames: true`. No `tabs`, `scripting`, `activeTab`, `contextMenus` or `commands`.

| Permission | Justification (paste) |
|---|---|
| `storage` | `Stores the user's settings: chosen AI provider, model, API keys, default languages, last used tone and language, and appearance. Nothing is sent to the developer.` |
| `alarms` | `Runs a once-a-day cleanup that deletes local rewrite and translation history older than 15 days.` |
| `https://openrouter.ai/*` | `Sends the text the user chose to rewrite or translate to OpenRouter with the user's own API key, after the user clicks; also loads OpenRouter's model list in Settings.` |
| `https://api.openai.com/*` | `Sends the text the user chose to rewrite or translate to OpenAI with the user's own API key, after the user clicks; also loads the user's available models in Settings.` |
| `https://generativelanguage.googleapis.com/*` | `Sends the text the user chose to rewrite or translate to Google Gemini with the user's own API key, after the user clicks; also loads available models in Settings.` |
| `https://api.groq.com/*` | `Sends the text the user chose to rewrite or translate to Groq with the user's own API key, after the user clicks; also loads available models in Settings.` |
| `https://translate.googleapis.com/*` | `Free translation: sends the selected text to Google Translate only after the user clicks Translate, so translation works without an API key.` |
| Content script on all sites | `Detects when the user selects text so it can show the Rewrite/Translate button next to the selection and, on request, insert the result into the field. It reads only the current selection, sends nothing until the user clicks, and does not read or store browsing history.` |

### Remote code

```
No. All JavaScript is bundled in the package. The extension only sends and receives data (text and JSON) from the APIs listed above.
```

## 4. Data usage disclosure

What the code actually does:

| Data | Where it goes | When | Stored |
|---|---|---|---|
| Selected or typed text (rewrite) | Chosen AI provider: OpenRouter, OpenAI, Google Gemini or Groq | After the user clicks Generate | Original + result saved in local IndexedDB history, auto-deleted after 15 days |
| Selected or typed text (translate) | Google Translate (`translate.googleapis.com`, default) or the chosen AI provider | After the user clicks the Translate button / popup Translate | Same local history |
| API keys | Only to the matching provider, in a request header | On requests and model-list loads | `chrome.storage.local` on this device only (not synced; moved out of sync in 1.0.14) |
| Settings, last tone/language, appearance | Nowhere | — | `chrome.storage.local` |
| Anything to the developer | Nothing. No backend, analytics, telemetry or crash reporting | — | — |

Recommended answers on the CWS "Data usage" form (conservative, because selected text and keys leave the device for third-party APIs):

- **Website content**: Yes. The text the user selects and asks to rewrite or translate is sent to the AI provider or Google Translate they chose.
- **Authentication information**: Yes. The user's own provider API keys are stored by the extension and sent only to that provider.
- **All other categories** (personally identifiable info, health, financial, personal communications, location, web history, user activity): No. The extension does not record clicks, keystrokes or visited pages.

Certifications (all true for the current code):

- I do not sell or transfer user data to third parties, outside of the approved use cases. (Data goes only to the provider the user picked, to do what they asked.)
- I do not use or transfer user data for purposes unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

Privacy policy URL: `https://birkankervan.github.io/ai-text-rewriter/PRIVACY_POLICY` (linked from Settings). It must be updated first; see discrepancies 2–5 below.

## 6. Discrepancies found (old listing / privacy policy / README vs code)

Resolved on 2026-10-12: items 2–5 by PRIV-02 (rewritten `docs/PRIVACY_POLICY.md`) and SEC-01 (keys and settings moved to `chrome.storage.local`); the Gemini `?key=` query and the OpenRouter `HTTP-Referer` in item 13 are also fixed.

1. **"Draggable window"** (old listing, README): the panel is anchored above or below the selection and cannot be dragged.
2. **Key storage location**: the privacy policy says keys are in `chrome.storage.local`. The code uses Plasmo `new Storage()`, whose default area is `sync`, so keys and settings sync across the user's Chrome profiles when Chrome Sync is on.
3. **Free Google Translate is not disclosed**: the privacy policy and old listing only mention AI providers. By default, translation sends selected text to `translate.googleapis.com` (unofficial `client=gtx` endpoint), with no key.
4. **Permissions misdescribed**: the privacy policy says the extension has host permission `<all_urls>`. It actually has 5 API host permissions; `<all_urls>` is only the content-script match (with `all_frames`).
5. **History**: the privacy policy says "IndexedDB/LocalStorage" and gives no retention period. History is IndexedDB only, stores original + result text with provider/model, and is auto-deleted after 15 days (alarm + on startup). Users can also delete entries or clear it all.
6. **Rewrite options**: the old listing and README list "Fix Grammar, Professional, Casual, Shorter, Longer, Paraphrase". The code has 6 tones (Professional, Friendly, Formal, Casual, Concise, Expanded) plus a Fix Grammar checkbox. There is no Paraphrase mode.
7. **Model names**: GPT-3.5, Claude 3.5 Sonnet, Gemini 1.5 Pro, Llama 3 and Mixtral are marketing claims. Models load from each provider at runtime. Hardcoded defaults (`llama3-8b-8192`, `google/gemini-2.0-flash-exp:free`) may be retired by the providers; worth checking.
8. **"Works on static text and dynamic inputs" for translation**: in editable fields the button is always Rewrite, never Translate. Translation inside a field only happens through Rewrite with a target language.
9. **Old CWS advice "Do you collect user data? No"** is risky: selected text and API keys are sent to third-party APIs, so "Website content" and "Authentication information" should be declared.
10. **package.json `displayName`/`description`** still carry the old title and say "OpenAI, Gemini, Groq", leaving out OpenRouter and free translation. The store name and the manifest name should match.
11. **README setup steps** say "right-click > Options, Select Active Provider, click Save". The real flow is: Settings icon in the popup or Options, pick a provider card, paste the key, then Connect and choose a model.
12. **Privacy policy title** uses "ai-text-rewriter" instead of the brand. The task brief mentions a root `PRIVACY_POLICY.md`, but only `docs/PRIVACY_POLICY.md` exists.
13. Code notes (not listing copy):
    - `src/hooks/use-models.ts:146` sends the Gemini key in the URL query (`?key=`), unlike the chat call, which uses a header.
    - `src/services/llm.ts` sends `HTTP-Referer: https://github.com/PlasmoHQ/plasmo` to OpenRouter, which credits the wrong app.
    - The existing `build/chrome-mv3-prod/manifest.json` is version 1.0.12 while package.json is 1.0.13. The build is stale, but its permissions are identical.
